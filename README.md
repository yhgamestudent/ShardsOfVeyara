# AGSD
## 기획
#### 농사 시스템
- 비트, 당근, 양배추, 토마토, 옥수수, 쌀, 밀, 수박, 호박 9종의 씨앗과 작물이 있음
- 토마토는 한번 수확 시 8개, 옥수수는 5개 수확됨. 나머지는 1개씩 수확됨
- 씨앗 수급 방법은 고민 중
  - 각 맵들을 탐험하면 맵에서 씨앗 파밍
  - 상인에게서 구매
  - 다른 방법 탐색
- 작물을 심으면 3일 후 완전한 작물로 성장
- 하루가 지날 때 마나 10% 확률로 밭에 잡초 생성
  - 잡초가 있는 밭은 다음날 성장하지 않음
  - 플레이어가 가서 잡초를 뽑아줘야함
    - 낫을 손에 들고 있을 시 뽑는 모션 없이 바로 뽑히게 할지 고민 중
#### 봉헌 시스템
- 단계별로 필요한 작물을 봉헌 시 플레이어의 체력이나 공격력 증가
#### 물약 제작 시스템
- 작물들과 차원 조각을 이용하여 여러 물약 제작 가능
- 하급 치유 물약: 20퍼 회복
- 중급 치유 물약: 40퍼 회복
- 상급 치유 물약: 70퍼 회복
- 하급 풍요 비약: 수확 시 +1개 더 수확
- 상급 풍요 비약: 수확 시 +2개 더 수확
- 하급 성장 비약: 작물 +1단계 성장
- 상급 성장 비약: 작물 +2단계 성장
- 레시피
  - 토마토 + 토마토 : 하급 치유 물약
  - 토마토 + 비트 : 중급 치유 물약
  - 토마토 + 수박 : 상급 치유 물약
  - 옥수수 + 당근 : 하급 풍요 비약
  - 옥수수 + 호박 : 상급 풍요 비약
  - 옥수수 + 옥수수 : 하급 성장 비약
  - 옥수수 + 양배추 : 상급 성장 비약
- 레시피대로 재료를 넣고 차원 조각을 넣으면 물약이 완성됨
- 만약 잘못된 레시피로 제작 시 솥 비우기를 해야하고 사용한 재료는 돌려주지 않음
#### 맵 해금 시스템
- 숲, 던전, 동굴, 도시 맵의 보스들을 잡으면 차원 구슬 조각이 떨어짐
- 거점 맵으로 돌아와 제단에 구슬을 바치면 다음 맵이 해금됨.
- 숲 > 던전 > 동굴 > 도시 순으로 해금
#### 게임 저장 시스템
- 맵을 이동 시 게임이 저장됨
  - 거점 맵을 제외한 맵에서는 자동 저장이 되지 않음
  - 거점 맵에서는 자동 저장이 활성화됨(5분 마다)
#### 시간 흐름 시스템
- 게임 내 하루는 현실 시간으로 6분
- 6시에 다음날로 넘어감
#### 전투 시스템
- forke를 무기로 사용
- 그냥 클릭 시 짧은 찌르기
- 앞으로 이동하면 공격 시 긴 찌르기를 하며 데미지가 좀 더 높은 대신 모션 시간이 긺
